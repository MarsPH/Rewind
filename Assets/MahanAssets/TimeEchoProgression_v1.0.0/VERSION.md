# Version 1.0.0

First standalone progression package for the accepted TimeEcho v1.0.8 foundation.

- Persistent scene-flow manager
- 20-map ordered campaign configuration
- Generated placeholder menu and win UI
- Optional intro, death, restart, next-map, win, and menu sequences
- Game Master voice, SFX, and guidance placeholders
- Asynchronous guarded scene loading
- Configurable death destination and previous-map chance
- Progress persistence
- Automatic v1.0.8 vitality, presentation, time, rewind, and collectible integration
- Exit, sequence-trigger, custom-menu, manual-death, and event-relay components
- Automatic editor installer, prefab generation, and validation
